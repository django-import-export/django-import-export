# Security Policy

## Reporting a Vulnerability

Please do not report security issues in public GitHub issues, pull requests or discussions.

You can report a vulnerability in either of the following ways:

1. **GitHub private vulnerability reporting (preferred)**: open the
   [Security tab](https://github.com/django-import-export/django-import-export/security/advisories/new)
   of this repository and click **Report a vulnerability**.
   This creates a private advisory which is visible only to the project maintainers and to you.

2. **Email**: send details to **djangoimportexport@gmail.com**.

The project maintainers will then work with you to resolve any issues where required, prior to any public disclosure.
